# Core contracts
Models use UUID id, created_at. Profile is one-to-one user; all data belongs to single authenticated account through user FK. BodyMeasurement(user, recorded_at, source, weight, body_fat, muscle, visceral_fat, body_age, bmr, bmi). SleepEntry(user,date,hours,note), CardioEntry(user,recorded_at,kind,minutes,note), Equipment(user,name). Profile(age,sex,height,goal,activity,timezone,summary_time,image_retention_days).
NutritionTarget(user,version,calories,protein,carbs,fat,fiber,reason) immutable newest version active. FoodEntry(user,recorded_at,name,quantity,calories,protein,carbs,fat,fiber,sugar,sodium,note,state,uncertainty,image,image_status). FoodLibrary(user,name,quantity,calories,protein,carbs,fat,fiber,sugar,sodium); MealTemplate(user,name,items JSON list food nutrient dicts).
Exercise(user,name,aliases JSON list,primary_muscles JSON list,secondary_muscles JSON list,equipment,classification). WorkoutPlan(user,version,name,schedule_type fixed|rotation,schedule JSON,exercises JSON,reason). schedule fixed is {"0":"Push"} weekday Monday=0; rotation list ["Push","Pull","Rest"]. exercises list {exercise: UUID string, day:"Push",order:1,sets:3,rep_min:8,rep_max:12,rir:2,rpe:null,rest:90,notes:""}. WorkoutSession(user,plan nullable FK, name,started_at,finished_at,notes). WorkoutSet(session,exercise,order,weight,reps,rir,rpe,set_type,completed,rest_seconds,failure,superset,notes).
core.services.active_target(user), active_plan(user), target_payload(target), plan_payload(plan), create_target(user,data,reason='',expected_version=None), create_plan(user,data,reason='',expected_version=None). Transactional versions lock user, compare expected_version, validate bounds and plan exercise references; raise ValidationError on stale/invalid. No mutation of old versions. AI should call create_* only on explicit Accept. Payload excludes id/version. nutrition_totals(user,start,end); weekly_volume(user); retain_images(); save_image(upload) -> filename. Call core Body save hook through coaching.services.on_body_saved if supplied (agent integration to confirm).
UI base template core/base.html blocks title/content/scripts, nav uses plain /coach/ and /coach/settings/. config.urls includes coaching.urls at /coach/. Authentication globally core.auth.LoginRequiredMiddleware; public paths /login/, /health, /static/, /manifest.webmanifest, /sw.js; any other route requires login. Settings include coaching if package exists. Media authenticated /photos/<uuid>/.
